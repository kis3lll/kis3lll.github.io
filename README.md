# Приглашение для Сони

Одностраничный сайт-приглашение. Открой `index.html` в браузере, чтобы проверить локально.

## Как выложить на GitHub Pages

1. Создай новый репозиторий на GitHub (например `sonya-date`).
2. Загрузи в него всё содержимое этой папки (`index.html`, `style.css`, `script.js`, папку `images/`) — сохраняя структуру папок.
3. Зайди в репозитории в **Settings → Pages**.
4. В разделе **Build and deployment** выбери **Source: Deploy from a branch**, ветку `main` и папку `/ (root)`. Сохрани.
5. Через минуту-две сайт будет доступен по ссылке вида `https://твой-логин.github.io/sonya-date/`.

## Если захочешь что-то поменять

- Текст и даты — прямо в `index.html`.
- Цвета и шрифты — в `style.css`, в самом верху файла (блок `:root`).
- Поведение кнопок и конфетти — в `script.js`.
- Фото — просто замени файлы в папке `images/`, сохранив те же имена (`sonya-1.jpg` … `sonya-5.jpg`), либо поменяй пути в `index.html`.
